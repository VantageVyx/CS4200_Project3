## Overview
Files to note: Main.java, and AlphaBeta.java contain the code for the implementation of this assignment. The 4 samples are located in /output.   

 Requirements: Java 8 or newer installation

 How to compile and run:  
 Open the project folder in the java IDE of your choosing and run Main.java.  
 
Alternatviely open the cmd prompt, navigate to Main.java, compile Main.java and AlphaBeta.java, and run.  

Compiling in the cmd line:   
 `javac Main.java AlphaBeta.java`  
Run:  
`java Main.java`
